# Фотографии тестового меню

Локальные JPEG, 1200 × 900. Используются только как иллюстрации тестовых позиций.

- `test-burger.jpg`: [Unsplash — бургер](https://unsplash.com/photos/_qxbJUr9RqI).
- `test-fries.jpg`: [Unsplash — картофель фри](https://unsplash.com/photos/VzGdnv5URPI).
- `test-combo.jpg`: [Unsplash — бургер, фри и соусы](https://unsplash.com/photos/j0RsNT1VxzU).

Позиции находятся в `src/data/testProducts.ts` и помечены `isTest: true`.
Для удаления из сохранённого меню используйте `/admin`; удалённые позиции не восстанавливаются при перезагрузке.
Для изменения стартового меню отредактируйте `testProducts.ts`. Уже сохранённые позиции меняются отдельно через `/admin`.
